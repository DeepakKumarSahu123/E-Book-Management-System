# 📚 E-Book Management System

## 📖 About the Project

The **E-Book Management System** is a web-based application developed to provide an online platform for managing and purchasing books. The application has separate functionalities for **Admin** and **Users**.

Users can create an account, log in, browse available books, search for books, add books to their cart, place orders, and view their order history. Administrators can manage books, categories, users, and orders.

---

## ⚙️ How It Works

### 👤 User

1. The user registers for an account.
2. After registration, the user can log in using their credentials.
3. Users can browse books available on the website.
4. Books can be searched or filtered by category.
5. Users can view book details and add books to the cart.
6. Users can proceed to checkout and place an order.
7. Users can view their previous orders through the order history.
8. Users can also manage their profile and account information.

### 🔐 Admin

1. The administrator logs into the admin section.
2. Admin can add new books and update existing book information.
3. Admin can delete books when required.
4. Admin can create and manage book categories.
5. Admin can view and manage registered users.
6. Admin can manage customer orders.

## 🏗️ Architecture

The application follows the **MVC (Model-View-Controller)** and layered architecture.

* **Model** – Represents application data and database-related objects.
* **View** – JSP pages used to display information to users.
* **Controller** – Servlets handle requests and connect the frontend with the backend.
* **DAO Layer** – Handles database operations using JDBC.
